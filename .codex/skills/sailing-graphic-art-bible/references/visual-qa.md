# Visual QA workflow

1. Modify the smallest relevant scene, asset, material, or script.
2. Run the actual Godot or Blender scene with the intended camera.
3. Capture screenshots from that camera at the required resolution and distance.
4. Compare them with the project checklist and reference A/B.
5. Write down failed items before making another change.
6. Fix only the concrete failures in scope.
7. Capture again and report evidence, not a self-rating.

For mobile sailing views, check composition, true 3D construction, color-block hierarchy, silhouette, cabin readability, sea/sky separation, distant-layer restraint, motion comfort, and absence of HUD/debug residue. If a screenshot cannot be produced or inspected, visual QA is incomplete.
