# LesusX Water Shader notice

This isolated benchmark uses the LesusX Water-Shader shader as the source for
`lesusx_water_b1_style_test_02.gdshader`.

Source repository: https://github.com/LesusX/Water-Shader

The shader is kept in the isolated `materials/water_test/` directory and is
not connected to Sea Trial or the formal project water. The benchmark script
only overrides material parameters at runtime; the eight Gerstner wave vectors
remain unchanged from the original demo.
