# 3D 资产比例指南

## 世界单位

项目统一约定：

> 1 Godot unit = 1 meter

所有导入的 GLB / GLTF / FBX 在放入场景前，先确认导入尺度、根节点缩放和 Pivot，不要用场景中的随机缩放掩盖单位错误。

## 当前主船参考尺寸

当前主船仍是 `visual_prototype_3d.gd` 中的程序化 PLACEHOLDER blockout。按运行时视觉层缩放后的近似包围尺寸记录如下：

| 部分 | 近似尺寸 |
| --- | ---: |
| 船体总长（含舵的视觉范围） | 1.8 m |
| 船体最大宽度 | 0.75 m |
| 船体/船舱高度 | 0.45 m |
| 总高度（含桅杆与帆装） | 2.5 m |

这些数字是当前原型的比例参考，不是正式船体建模规格。正式主船替换时，优先保持“可辨认船舱 + 船体 + 桅杆 + 帆”的整体比例，再做必要的视觉调整。

## 环境尺寸参考

以下是导入早期的合理起点，最终仍以游戏摄像机截图和构图为准：

| 资产 | 推荐范围 |
| --- | ---: |
| 小型海边建筑宽度 | 2–6 m |
| 小型海边建筑高度 | 2.5–5 m |
| 小型灯塔高度 | 8–18 m |
| 码头甲板高出水面 | 0.2–0.45 m |
| 小型码头单段宽度 | 1.5–3 m |
| 近岸岩石高度 | 0.3–2 m |

## 替换原则

- 将导入模型放在对应场景的 `VisualRoot` 或专用资源子场景中。
- 视觉模型的 Pivot 应位于合理的底部/接触面附近。
- 视觉与 Collision 必须分开维护。
- 不默认使用正式模型的复杂 Mesh Collider。
- 任何尺度异常先修正导入设置或模型源文件，不要修改核心航行代码。
